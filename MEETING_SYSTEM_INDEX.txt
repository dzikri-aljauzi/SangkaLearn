================================================================================
                        HOW IT WORKS (SIMPLE)
================================================================================

1. ADMIN CREATES MEETING
   → Navigate to /admin/courses/{course}/meetings
   → Add title, Zoom link, date/time
   → Meeting created
   → Attendance records auto-created for all students

2. STUDENTS COMPLETE COURSE
   → Complete lessons + quizzes + assignments = 100%
   → Automatically added to certificate queue
   → Meeting attendance calculated

3. ADMIN REVIEWS CERTIFICATE REQUEST
   → Navigate to /admin/certificate-queue
   → View student's meeting attendance
   → Upload screenshot proof
   → Mark who attended each meeting

4. ADMIN APPROVES/REJECTS
   → If attended all meetings → Approve + upload certificate
   → If didn't attend → Reject with reason
   → Student receives certificate or rejection notice

================================================================================
                        KEY PRINCIPLES
================================================================================

✅ Meetings DO NOT count toward course progress
✅ Progress = Lessons + Quizzes + Assignments ONLY
✅ 100% Progress = Auto-enter certificate queue
✅ Admin manually checks meeting attendance
✅ Admin approves or rejects certificate
