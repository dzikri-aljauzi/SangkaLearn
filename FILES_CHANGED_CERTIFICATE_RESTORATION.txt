DATA FLOW (CORRECT)
==============================================================

1. Student completes course → progress_percentage = 100
2. Enrollment status = 'active' (not 'completed' yet!)
3. NO certificate record exists yet
4. Admin visits /admin/certificates
5. Controller queries:
   - Enrollments WHERE progress = 100 AND status = 'active'
   - AND NOT EXISTS in certificates table
   → Result: Students READY for certificate
6. Frontend displays list with AppLayout (sidebar appears!)
7. Admin can:
   - Click "Review Detail" → See Phase 1-6 features
   - Click "Upload" → Upload PDF manually
8. On certificate upload/generate:
   - System validates meeting attendance
   - If pass: Issue certificate, update enrollment status to 'completed'
   - If fail: Show error, block issuance

TECHNICAL DETAILS
==============================================================

AppLayout vs AuthenticatedLayout:
- AppLayout: Admin pages (has sidebar in line 34)
  Location: resources/js/Layouts/AppLayout.jsx
  Features: Sidebar navigation, role-based menu, responsive

- AuthenticatedLayout: Other sections (no sidebar for admin)
  Should NOT be used for admin certificate pages

Data Source:
- enrollments table: Source of 100% completion students
  Column: progress_percentage (calculated from lessons+quizzes+assignments)

- certificates table: Already issued certificates
  Linked to enrollments via user_id and course_id

- certificate_queue table: Phase 1-6 approval workflow
  NOT used for listing 100% students
  Only used for approval process integration

Meeting Attendance:
- Tracked in meeting_attendances table
- Validated during certificate issuance
- NOT counted in progress_percentage (100% = course completion only)
- But REQUIRED for certificate approval

Controller Methods Flow:
```
index()
  ↓
  Queries enrollments (100%)
  ↓
  Returns completedEnrollments, certificates, stats
  ↓
  Frontend: Index.jsx (AppLayout)
  ↓
  User clicks "Review Detail"
  ↓
show($enrollmentId)
  ↓
  Loads enrollment with meetings, screenshots
  ↓
  Returns enrollment, progress, meetingAttendances
  ↓
  Frontend: Show.jsx (Phase 1-6 features)
  ↓
  User uploads/generates certificate
  ↓
store(Request) OR generateCertificate($enrollmentId)
  ↓
  Validates meeting attendance
  ↓
  Creates certificate record
  ↓
  Updates enrollment status to 'completed'
  ↓
  Sends notification to student
```
